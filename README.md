# Бот для ежедневной рутины

Вода (с прогрессом и ежедневным сбросом), ИМТ, расписание уроков с напоминаниями. Всё управляется кнопками.

## 1. Получи токен
В Telegram напиши @BotFather → `/newbot` → скопируй токен.

## 2. Запусти у себя
```bash
pip install -r requirements.txt
export BOT_TOKEN="твой_токен"      # Windows PowerShell: $env:BOT_TOKEN="твой_токен"
python bot.py
```
Открой бота в Telegram и нажми Start.

## 3. Залей на GitHub
```bash
git init && git add . && git commit -m "bot"
git branch -M main
git remote add origin https://github.com/ТВОЙ_ЛОГИН/routine-bot.git
git push -u origin main
```
Токен в репозиторий не кладём, только в переменные окружения хостинга.

## 4. Чтобы работал 24/7 (нужно для напоминаний)
GitHub сам бота не запускает. Подключи репозиторий к хостингу:
- **Render / Railway / Fly.io**: создай сервис типа *Worker*, Build: `pip install -r requirements.txt`, Start: `python bot.py`.
- Добавь переменные: `BOT_TOKEN`, при необходимости `DEFAULT_TZ` (по умолчанию `Asia/Almaty`) и `DB_PATH`.
- Данные лежат в SQLite-файле. На бесплатных тарифах диск часто стирается при перезапуске, поэтому подключи постоянный диск (volume) и укажи `DB_PATH=/data/bot.db`.

## Как вставлять расписание
1. **Расписание → Звонки**: одним сообщением по строке на урок, например `08:30-09:15`.
2. **Расписание → Уроки по дням**: выбери день и пришли названия по порядку, по строке на урок. Окно обозначай «-».
3. **Настройки**: за сколько минут напоминать (5, 10, 15), норма воды, часовой пояс.

## Домашка
После урока просто напиши боту сообщение вида `Математика №12–15` (можно сокращать: `мат №12–15`, можно несколько предметов по строке). Бот сам найдёт следующий урок этого предмета по расписанию и сохранит задание. Сделать его нужно накануне урока до 00:00. Напоминания приходят в выбранное в настройках время и в 21:00, пока задание не отмечено кнопкой ✅. Кнопка «📚 Домашка» показывает всё невыполненное.

## ИИ (Gemini)
1. Зайди на aistudio.google.com → Get API key и создай бесплатный ключ.
2. Добавь его в переменные окружения хостинга: `GEMINI_API_KEY`. Название модели можно поменять переменной `GEMINI_MODEL` (по умолчанию `gemini-flash-latest`), если Google переименует модели.
3. **Помощь с заданиями:** пришли боту фото задания, выбери «Только решение» или «С объяснением по шагам». Класс ученика задаётся в Настройки → Класс.
4. **Выходные:** бот раз в неделю спрашивает у Gemini праздничные и перенесённые выходные в Казахстане и не ставит на них домашку и напоминания об уроках. ИИ может ошибаться, поэтому всё проверяется и правится в Настройки → Выходные (можно добавить дату или каникулы вручную).
